# assets/oraculo

Material del PDF del Oráculo (generador en `src/lib/oraculo/`).

- `fonts/` — Montserrat, Lora y Lato, tipografías libres con licencia SIL OFL 1.1 (los textos de licencia van al lado). Descargadas del repositorio `google/fonts`.
- `glifos/<slug>-bronce.png` y `<slug>-oro.png` — los 20 glifos recoloreados desde `src/assets/glifos/*.jpg` (grises) con `python3 scripts/oraculo/recolorear-glifos.py`. Bronce para papel crema, oro para páginas oscuras.
- `logo-azul-anaite-marfil.png` — el logo de `src/assets/logo-azul-anaite.png` teñido de marfil, para fondo oscuro.
